# Особенности Flutter для ОС Аврора

1. Не все Flutter-плагины из pub.dev имеют совместимую платформенную реализацию для Авроры.
2. Проверяй плагины на своей версии Flutter/Aurora SDK и на целевом устройстве.
3. Чистый Dart (фильтры, вычисления, `csv`, JSON) обычно переносится проще, чем камера, GPS, файлы и системные диалоги.
4. `path_provider`, `file_picker`, `image_picker`, `sqflite`, `url_launcher` и аналоги могут требовать специальной реализации/конфигурации.
5. При экспорте используй доступный приложению каталог; файл внутри приватного каталога не обязательно виден пользовательскому файловому менеджеру.

## Алгоритм решения задачи
- Найди текущую модель данных.
- Напиши отдельную функцию обработки данных.
- Проверь функцию тестом.
- Добавь кнопку и показ статуса.
- Проверь запуск на устройстве.
- Зафиксируй изменения в Git.

Документация: https://developer.auroraos.ru/ и https://pub.dev/ (совместимость пакета проверять отдельно).
