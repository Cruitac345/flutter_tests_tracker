# 20 возможных тренировочных заданий Volga IT

Это **авторские тренировочные сценарии**, не задания олимпиады 2026.

1. Сделать поиск расходов по названию.
2. Добавить фильтр по категории.
3. Отфильтровать расходы за период.
4. Посчитать итоговую сумму.
5. Посчитать сумму каждой категории.
6. Сортировать операции по дате.
7. Добавить форму редактирования записи.
8. Показывать подтверждение удаления.
9. Сохранить фильтр между запусками.
10. Добавить экспорт CSV через пакет csv.
11. Добавить импорт CSV с проверкой формата.
12. Сформировать PDF-отчёт.
13. Открыть ссылку через url_launcher.
14. Прикрепить фото чека.
15. Переименовать приложенное фото.
16. Обрезать изображение.
17. Сохранить фото в доступный каталог.
18. Получить данные из HTTP JSON API.
19. Сохранить точки GPS и показать координаты.
20. Написать тесты и оформить отдельную Git-ветку.

Практика по CSV и отчётам: [REPORT_TASKS.md](REPORT_TASKS.md).
