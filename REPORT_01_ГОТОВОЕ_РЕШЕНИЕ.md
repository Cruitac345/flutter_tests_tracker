# ⭐ ЗАДАНИЕ: Сформировать отчёт о расходах за период

**Тренировочное условие:** пользователь выбирает даты «с» и «по», нажимает «Экспорт», получает `report.csv` со списком операций и итогом; `summary.csv` содержит суммы по категориям. Бонус — PDF.

## 1. Подключи пакет
В `pubspec.yaml`:
```yaml
dependencies:
  csv: ^8.0.0
```
В ветке 8.x используется `Csv(...).encode(rows)` и `Csv(...).decode(text)`; старые примеры с `ListToCsvConverter` относятся к другой версии.

## 2. Скопируй код
Открой [report_service.dart](report_example/lib/report_service.dart): `filterExpenses`, `totalAmount`, `categoryTotals`, `buildDetailsCsv`, `buildSummaryCsv`, `parseDetailsCsv`, `saveCsv`.

Деньги храним в **целых копейках**, даты фильтруем **включительно**, CSV кодируем пакетом, а не через `split(',')`.

## 3. Запуск
```bash
cd report_example
dart pub get
dart run bin/main.dart
dart test
```
Результат в `output/report.csv` и `output/summary.csv`.

## 4. Аврора
Пиши файлы в доступный каталог приложения, например полученный через совместимый с Авророй `path_provider`. Для сохранения в произвольную папку нужен поддерживаемый механизм выбора/обмена файлами.

## 5. PDF
См. [pdf_report.dart](report_example/lib/pdf_report.dart). Для русского текста нужен лицензированный TTF-шрифт с кириллицей. Генерация PDF и возможность печати — разные задачи.

## Ошибки
- `split(',')` ломает поля с кавычками и разделителями.
- Фильтр по точному времени может потерять операции в конце дня.
- `double` не лучший формат хранения денежных сумм.
- Excel иногда требует UTF-8 BOM и разделитель `;`.
- Строку `ИТОГО` нельзя импортировать как новый расход.
