Подготовка к практическим задачам: короткие шпаргалки, примеры кода и тренировочные задания. **Это не официальные задания финала 2026 года.**

## ⭐ Начни с отчётов

1. [Пошаговое задание «Отчёт + CSV»](REPORT_01_ГОТОВОЕ_РЕШЕНИЕ.md)
2. [Исходник CSV-отчёта на пакете csv](report_example/lib/report_service.dart)
3. [Генерация PDF](report_example/lib/pdf_report.dart)
4. [Консольный пример](report_example/bin/main.dart)
5. [Тесты отчёта](report_example/test/report_service_test.dart)
6. [Практика](practice/REPORT_TASKS.md)

В папке `report_example`:

```bash
dart pub get
dart run bin/main.dart
dart test
```

Обучающие примеры требуют проверки на вашей версии Aurora SDK. Чистая Dart-логика CSV и расчётов не зависит от платформы, а файловые каталоги, выбор файлов и открытие документов требуют проверки поддерживаемых плагинов.
